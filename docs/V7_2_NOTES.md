# V7.2 balance-reflex experiment

V7.2 tests whether balance recovery improves when memory indexes both posture and motion tendency. The baseline remains V6.1. V7.2 only applies a remembered reflex after the pre-fall detector fires and only when a sufficiently close historical reflex exists.

Primary metrics: survival steps, energy proxy, simulations per step, risk events, reflex hits and reflex misses. Negative results are retained as evidence.
